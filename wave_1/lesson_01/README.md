- [Презентация PPTX, v12](slides/lesson_01_llm_intro_v12.pptx).

- [Python API workshop](python_api/README.md): подготовка окружения и запуск ячеек с запросами к модели.

Введение: токены, контекст, роли, параметры генерации, формулировка задачи и проверка результата. В практике сравнивайте ответы на одинаковых входах и проверяйте код тестами.

Python workshop — дополнительный материал. Запускайте отдельные ячейки по инструкции, а не весь файл сразу. Настройки и доступность API зависят от вашего провайдера; значения в `.env.example` — примеры конфигурации. Ключи храните только локально.
