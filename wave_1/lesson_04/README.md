Практика объединяет инструменты, агентный цикл, ограничения на пути и запись, трассу и проверку результата тестами. Сначала запустите офлайн-показ с `ScriptedProvider`, затем при желании подключите совместимый сервер локальной модели.

`ScriptedProvider` имитирует решения модели для повторяемого показа; файловые операции и тесты выполняются по-настоящему. Для демонстрации правок используйте временную копию `sample_repo`, как показано в инструкции.
