# Практика занятия 03: один кейс от LLM до RAG

Во всех первых шагах используется один конкретный вопрос:

> 15 сентября 2025 года при покупке железнодорожного билета сайт сам добавил
> платную страховку. Покупатель ничего не выбирал, галочка уже стояла. Можно
> ли отменить страховку, вернуть деньги и как быстро сайт должен это сделать?

Опорная норма: Федеральный закон от 07.04.2025 № 69-ФЗ. Он изменил статью 16
Закона о защите прав потребителей, добавил пункт 3.1 и действует с 01.09.2025.
Для требования о возврате закон устанавливает срок три дня. Поэтому результат
можно проверить по реквизитам, условиям и официальному источнику.

## Последовательность

| Файл | Что меняем | Что видно в выводе |
|---|---|---|
| `00_plain_llm.py` | Только вопрос к LLM | Модель может назвать закон и дату неверно или пропустить важное условие |
| `01_fulltext_search.py` | Добавляем поиск по совпадениям слов | Запрос языком закона находит статью 1. Живой вопрос ставит выше правило о периоде охлаждения |
| `02_vector_search.py` | Представляем запрос и документы embeddings | Живой вопрос находит правило об автодобавленной услуге |
| `03_bad_chunking_rag.py` | Режем исходный закон каждые 280 символов, overlap=0, top_k=1 | Один фрагмент не содержит одновременно согласие, запрет, возврат и дату |
| `04_structured_rag.py` | Собираем действующую статью с метаданными | Контекст и ответ проходят восемь явных критериев |
| `05_multi_rag_router.py` | Добавляем вопрос о сокращённом совместителе | Global top-1 теряет одну тему. Router запускает отдельные consumer и labor RAG |
| `06_versioned_update.py` | Загружаем новую редакцию | Старая версия остаётся для 31.08, новая выбирается для 15.09 |

Каждый пример печатает найденные фрагменты, переданный в LLM контекст и строки
`[PASS]` или `[FAIL]`. Провал вычисляется по результату, а не задан комментарием.
Ответы LLM могут меняться после смены модели.

В проверенном прогоне `00_plain_llm.py` Gemini назвала дату 01.09.2022 и сроки
7 или 10 дней. В официальной норме: 69-ФЗ, п. 3.1 ст. 16, дата 01.09.2025 и
три дня со дня предъявления требования. Это реальный результат запуска, а не
заранее записанная ошибка.

## Запуск

Из этой директории:

```bash
source ../../.venv/bin/activate
python workflow_legal_agent.py --step plain
python workflow_legal_agent.py --step fulltext
python workflow_legal_agent.py --step vector
python workflow_legal_agent.py --step bad-chunks
python workflow_legal_agent.py --step structured-rag
python workflow_legal_agent.py --step routing
python workflow_legal_agent.py --step versions
```

Весь workflow:

```bash
python workflow_legal_agent.py --step all
```

Шаги `plain`, `vector`, `bad-chunks`, `structured-rag` и `routing` обращаются
к Gemini API. Перед запуском передайте ключ через переменную окружения
`GEMINI_API_KEY`; не сохраняйте его в репозитории.

Проверки без API:

```bash
python -m pytest -q test_examples_offline.py
```

## Что называем поиском

- Полнотекстовый поиск в шаге 1 ранжирует документы по совпадающим словам.
  Учебная реализация использует TF-IDF. Это не замена PostgreSQL FTS или
  Elasticsearch.
- Embedding это числовое представление текста. Векторный поиск сравнивает
  embeddings по cosine similarity.
- Векторный поиск не отвечает на вопрос сам. Он только выбирает фрагменты,
  которые RAG передаст модели.

В `legal_corpus.py` приведены учебные выдержки с реальными реквизитами.
В рабочей системе ingestion должен хранить официальный снимок текста, hash,
дату получения, период действия и связь закона-изменения с нормой, которую он
меняет.

## Домашняя работа

`coding_agent_with_cookbook_rag.py` это отдельная домашняя часть. Coding agent
из занятия 02 получает поиск по локальной книге *Python Cookbook*. PDF не
копируется в проект и не входит в архив.

```bash
python coding_agent_with_cookbook_rag.py \
  --repo ../coding_agent/sample_repo \
  --book "/Users/vasily/Downloads/D. Beazley, B.K. Jones - Python Cookbook, 3rd Edition. 2013.pdf" \
  --task "Найди причину падения average([]), используй Cookbook и предложи исправление"
```

Проверка ingestion без ключа и без запроса к Gemini:

```bash
python coding_agent_with_cookbook_rag.py \
  --book "/Users/vasily/Downloads/D. Beazley, B.K. Jones - Python Cookbook, 3rd Edition. 2013.pdf" \
  --check-book
```

На приложенном PDF ingestion проверен: 812 чанков из 226 рецептов, максимум
1800 символов. Приложение и предметный указатель исключены. Агент работает
read-only: воспроизводит тест, читает код, вызывает Cookbook RAG и просит
подтверждение перед изменением.
