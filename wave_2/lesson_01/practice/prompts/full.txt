# Задача
Напиши на Python функцию parse_duration(text: str) -> int.
Она переводит строку с длительностью в число секунд.

# Правила
- Части вида <целое><единица>: h — часы, m — минуты, s — секунды.
- Регистр любой. Пробелы между частями и по краям допустимы.
- Каждая единица не больше раза, порядок строго h, m, s.
- Число может быть больше 59: "90m" — это 5400.
- Иначе ValueError: пустая строка, число без единицы, дробь,
  чужая единица, повтор, другой порядок.
- Только стандартная библиотека.

# Примеры
"2h15m" -> 8100    "3m 5s" -> 185    "7" -> ValueError

# Формат ответа
Только код функции в одном блоке ```python```, без пояснений.
