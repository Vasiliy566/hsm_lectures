# Магазин «Север»: учебный проект

Тот же магазин, что на занятии 1.2. Ошибку со статусом `picking` уже исправили. Все данные вымышленные.

- `shop/orders.py` — статусы заказа и правило смены адреса;
- `shop/delivery.py` — срок доставки, в том числе экспресс;
- `shop/pricing.py` — цена со скидкой;
- `tests/` — тесты, запуск: `python -m unittest discover -s tests`.

Правила магазина описаны не в коде, а в регламентах поддержки.
