# Практика занятия 1.3: контекст и RAG

Код, который преподаватель показывает на занятии. Повторять вместе с ним не обязательно: всё можно запустить потом.

Каждый показ — один файл, читается сверху вниз. Вспомогательный код лежит в `helpers/`, его можно не открывать.

## Установка

```bash
cd practice
pip install -r requirements.txt
cp .env.example .env    # впишите OPENAI_API_KEY и OPENAI_MODEL
```

## Показы

| Файл | Что показывает | Нужен ключ |
|---|---|---|
| `01_without_and_with_docs.py` | вопрос поддержки без регламента и с регламентом во входе | да |
| `02_three_searches.py` | один вопрос: поиск по словам, по смыслу и гибрид | для шагов 2–3 |
| `03_chunking.py` | нарезка по размеру и по пунктам: что находится и что отвечает модель | для шага 3 |
| `04_mini_coder.py` | мини-кодер с поиском по регламентам решает задачу SEV-418 | да |

Свой вопрос для поиска: `python 02_three_searches.py "Сколько стоит экспресс-доставка?"`.

## Что где лежит

- `data/` — регламент изменения заказа двух редакций, FAQ поддержки и 20 вопросов для проверки поиска. Магазин и правила вымышленные.
- `project/` — магазин «Север» из занятия 1.2. Мини-кодер работает с копией в `sandbox/`.
- `checks/` — проверка задачи SEV-418. Модель её не видит.
- `cache/` — эмбеддинги сохраняются здесь после первого запуска, повторный запуск их не пересчитывает.
- `runs/` — трассы мини-кодера.
