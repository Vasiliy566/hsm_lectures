# Материалы второго занятия

Тема: structured output, tool calls и skills. На практике собираем мини-кодер, который исправляет ошибку в учебном магазине. В домашке переносим эти идеи в агента для репозиториев реального размера.

## С чего начать

1. Откройте [презентацию занятия](lesson_02_slides.pdf).
2. Повторите упражнения из [PRACTICE_ROUTE.md](PRACTICE_ROUTE.md). Первый маршрут работает без API-ключа.
3. Выполните задание в [homework_02_agent/README.md](homework_02_agent/README.md).
4. Отправьте агента по [гайду Planerverse](PLANERVERSE_GUIDE.md) до **29 октября 2026, 23:59 МСК**.
5. Выберите материал из [READING_RU.md](READING_RU.md), если хотите разобраться глубже. Не нужно читать и смотреть всё подряд.

Гайд по сдаче и подборка чтения также собраны в [одном PDF](lesson_02_student_guide.pdf) с кликабельными ссылками.

## Как получить код

Скачайте репозиторий через кнопку GitHub **Code**, затем **Download ZIP**, либо клонируйте его:

```bash
git clone https://github.com/Vasiliy566/hsm_lectures.git
cd hsm_lectures/wave_2/lesson_02
```

[Практика занятия](practice/README.md) находится в `practice/`, [заготовка домашнего задания](homework_02_agent/README.md) в `homework_02_agent/`. Установка и запуск для macOS, Linux и Windows описаны в [маршруте практики](PRACTICE_ROUTE.md).

## Что должно остаться после занятия

- Вы отличаете валидный JSON от соответствия схеме и от фактической корректности ответа.
- Можете показать, где модель предлагает вызов функции, где программа его исполняет и как возвращает результат по `call_id`.
- Понимаете разницу между инструкцией, skill и инструментом. Skill сам по себе не выдаёт права на запись и не создаёт отсутствующий инструмент.
- Умеете ограничить цикл агента и корректно обработать незавершённый ответ, не разбирая обрезанный JSON.
- Проверяете результат по изменениям файлов и тестам, а не по заявлению модели «готово».

## Уточнение к слайду с домашкой

На слайде 31 обработка `incomplete` ещё указана «по желанию». В обновлённом демо Planerverse она проверяется специально, поэтому подготовьте её перед сдачей. Текущие ограничения стенда смотрите в [технической инструкции](https://planerverse.ru/participant-agents.md).

`practice/` и `homework_02_agent/` решают разные задачи. Не отправляйте весь репозиторий курса как репозиторий агента: создайте отдельный репозиторий из содержимого `homework_02_agent/`, чтобы `agent.json` находился в корне. Преподавательские решения не опубликованы.
