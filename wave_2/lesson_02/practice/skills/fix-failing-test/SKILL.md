# Исправление по падающему тесту

1. Запусти `run_tests` и найди упавшие тесты. Если всё проходит — ничего не меняй и сообщи об этом.
2. Прочитай файл упавшего теста и файл с функцией, которую он проверяет. Не угадывай пути: сначала `list_files`.
3. Найди причину. Исправляй код, а не тест: тесты описывают правило, которое нужно соблюсти.
4. Сделай минимальную правку: меняй только то, что нужно для этого правила.
5. Снова запусти `run_tests`. Если тесты падают — разберись ещё раз, но не больше двух попыток.
6. Верни отчёт по схеме. Поля и примеры — в [references/report.md](references/report.md).

Если записи файлов нет среди доступных действий или она запрещена — не делай вид, что исправил:
верни `status: not_fixed` и опиши, какую правку нужно внести.
