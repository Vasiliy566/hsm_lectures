# Отчёт после исправления

- `status`: `fixed` — правка сделана и тесты прошли; `not_fixed` — правки нет или тесты падают;
  `explained` — правку не просили, дан только разбор; `need_info` — не хватает данных.
- `changed_files`: только реально изменённые файлы. Пустой список, если ничего не записано.
- `tests_passed`: результат последнего `run_tests`, а не ожидание. `null` — тесты не запускались.
- `skill_used`: имя загруженного skill или null.
- `summary`: что было не так и что изменено, 1–3 предложения.

Пример:

```json
{"status": "fixed", "changed_files": ["shop/orders.py"], "tests_passed": true,
 "skill_used": "fix-failing-test",
 "summary": "picking был в списке разрешённых статусов. Убрал его, тесты проходят."}
```
