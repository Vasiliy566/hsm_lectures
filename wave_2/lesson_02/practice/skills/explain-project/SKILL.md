# Объяснение проекта

1. Начни с `list_files` для корня, затем прочитай README.md.
2. Читай только файлы, которые нужны для ответа на вопрос.
3. Отвечай для человека, который видит проект впервые: что делает каждый нужный файл, одним предложением.
4. Ничего не записывай, даже если заметил ошибку: упомяни её в ответе.
5. В отчёте по схеме: `status: explained`, `changed_files: []`, `tests_passed` — результат `run_tests`, если запускал, иначе `null`.
