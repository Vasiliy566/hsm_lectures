# Магазин «Север»: учебный проект

Небольшой код магазина для практики занятия 1.2. Все данные вымышленные.

- `shop/orders.py` — статусы заказа и правило смены адреса;
- `shop/delivery.py` — срок доставки;
- `shop/pricing.py` — цена со скидкой;
- `tests/` — тесты, запуск: `python -m unittest discover -s tests`.

Правило магазина (то же, что в заказе A127 на занятии 1.1):
адрес можно изменить, пока сборка не началась — статусы `new` и `paid`.
После начала сборки (`picking`) и после отправки (`shipped`) — нельзя.
